# UWW Referee Practice Examination 2026

Interactive multilingual referee-development assessment for **Category III, II, I and IS**.

**Current version: V1** — official UWW logo and multilingual examination (English, Spanish, French and Russian).

## Live site

https://coachgalva.github.io/uww-referee-practice-exam-2026/

## Languages

- English — default and controlling educational version
- Spanish
- French
- Russian

The language selector changes the interface, questions, answer options and model answers instantly.

## Features

- 48 questions across four progressive levels
- Greco-Roman, Freestyle and Women’s Wrestling
- Multiple-choice automatic scoring
- Open-response model answers and self-review
- Per-category progress stored in the browser
- Responsive and print-friendly layout
- Official UWW logo asset sourced from `uww.org`
- Direct links to official UWW rules and circulars

## Authority notice

This is educational practice material, not an official UWW certification examination. The controlling source is the *International Wrestling Rules — January 2026*. The English rule text prevails in case of discrepancy. Use of the UWW name and logo identifies the subject and source organization; it does not imply official endorsement of this practice examination.
