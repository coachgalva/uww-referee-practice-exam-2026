# UWW Referee Practice Examination 2026

Interactive, self-contained HTML evaluation form for referee development across **Category III, II, I and IS**.

## Features

- 48 questions in four progressive levels
- Multiple-choice automatic scoring
- Open-response model answers and self-review
- Per-category progress and persistent browser storage
- Responsive and print-friendly layout
- Official UWW sources linked in the application

## Use

Open `index.html` directly in a browser. No build step or external dependency is required.

## Authority notice

This is educational practice material, not an official UWW certification examination. The controlling source is the *International Wrestling Rules — January 2026*. The English rule text prevails in case of discrepancy.
